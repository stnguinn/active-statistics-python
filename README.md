# active-statistics-python
# Active Statistics with Python

## Project Purpose

This repository documents my structured study of statistics using Python. The project is based on a long-form statistics learning plan focused on practical statistical reasoning, simulation, probability, uncertainty, data analysis, and reproducible notebook-based work.

The goal is to build a public, employer-ready portfolio that demonstrates:

- Statistical reasoning
- Python-based data analysis
- Simulation-based thinking
- Clear written interpretation of results
- Reproducible notebooks
- Professional project organization

This repository is intended to support future work in data analytics, decision science, operations research, consulting, and applied statistical analysis.

---

## Primary Tools

The main tools used in this repository are:

- Python
- Jupyter Notebook
- pandas
- numpy
- matplotlib
- scipy
- statsmodels
- scikit-learn
- Git and GitHub
